# 求偶展示、叼枝运材与简化筑巢：物种证据及首版决策

调研及来源访问日期：**2026-10-24**。范围：现有 `shared/species.json` 的 46 鸟种，仅规划 macOS；本轮只有调研与本文档，不开发、不提交、不编译。背景为 `docs/MACOS-BEHAVIOR-ROADMAP.md`；本文不修改该路线图，也不研究浴盆、捕虫或食盘。

**文档优先级：本文是物种证据与设计解释，不是实施合同。唯一实施合同为 [macOS 行为内容实施规格](../BEHAVIOR-CONTENT-SPEC.md)，尤其第 4.5、4.6 节；素材、人数、状态顺序、数值、提交点和完成记录均以该文件为准。** 下文合同摘录仅便于对照，不形成第二份可独立调参的规格；其余设计解释不覆盖主规格。

## 1. 明确选定：M7a、M7b、M7c 均先做珠颈斑鸠

根据本轮整合方向，**三个批次的唯一首版鸟种均为珠颈斑鸠 `spottedDove`，对应 `Spilopelia chinensis`**，不再保留多物种候选名单。

| 批次 | 明确行为 | 首版可见结果 | 证据与设计边界 |
| --- | --- | --- | --- |
| M7a | 珠颈斑鸠求偶姿态展示 | 两个角色：发起者抬身、缓慢鞠躬，观看者观察，双方恢复 | [S1][S2][S3] 支持该物种的求偶动作。当前只做角色演示，不表示已判定雄雌或形成繁殖配对 |
| M7b | 珠颈斑鸠叼取细枝并短途运材 | 看枝、拾枝、衔住移动、放枝、离开 | [S1] 直接记录衔材；[S2][S3] 支持枝材。独立运材演示不必生成完整巢，不宣称模拟自然双鸟分工 |
| M7c | 珠颈斑鸠简化筑巢 | 运枝结束后另一次单鸟整理已送达枝条，逐步出现稀疏浅盘／平台 | [S1][S3][S4] 支持浅盘、松散枝平台。仅完成视觉巢体，不进入产卵、孵化或育雏 |

这一选择同时满足物种证据和素材复用：M7b 的拾取、喙锚附着、带物移动、放置均可被 M7c 复用；M7a 的鞠躬需要独立素材。**M7a 不是 M7c 的繁殖成功前置条件**，只表示开发批次顺序。

麻雀、喜鹊和家燕已有可用的物种资料，但**首版明确暂缓**。它们不能共享珠颈斑鸠的完整动作与巢形模板；灰喜鹊也不因名称相近而获得喜鹊的证据资格。

## 3. 来源与逐项设计判定

以下均为中文概括。每项注明支持与不支持的设计；文内 `[S编号]` 对应本节具体 URL。没有把同属、同科或同名鸟的资料推广到其他物种。

### S1：中国野外研究，直接支持珠颈斑鸠求偶、衔材和浅盘巢

- **标题**：《四川南充市区珠颈斑鸠的繁殖生态学和巢址选择》；英文题名 *Breeding Ecology and Nest-site Selection of the Spotted Doves in Northeastern Sichuan, China*。
- **作者／出版**：周友兵等，《动物学杂志》2006，41(3)：7–12；中国科学院西双版纳热带植物园机构知识库提供原文。
- **URL**：https://ir.xtbg.ac.cn/bitstream/353005/1841/1/四川南充市区珠颈斑鸠的繁殖生态学和巢址选择.pdf
- **访问日期**：2026-10-24。
- **核对位置与方式**：原刊第 8 页，2.1「求偶与交配」、2.2「营巢及巢址选择」；已读取公开 PDF 的正文文本。网页抓取超时后，通过公开文件在内存中提取核对，未声称完成图片或巢照核验。
- **证据**：南充研究记录走动、点头鞠躬及颈羽表现；筑巢时雄鸟主要供材，雌鸟营巢并少量衔材；还记录衔材交付。巢体浅盘状，以枝条构成。
- **支持设计**：三批次统一选择珠颈斑鸠；有依据地制作鞠躬、衔枝、运送、放枝及浅盘枝巢。
- **不支持设计**：把无性别个体宣称为雄雌配对；把单鸟完成全部工序宣称为真实分工；将文中当地观察固化为所有个体的步数、工期或运输频率。

### S2：香港观鸟会，校验中国种群身份及动作特征

- **标题**：*Spotted Dove 珠頸斑鳩*，The Avifauna of Hong Kong。
- **机构／版本**：Hong Kong Bird Watching Society；Leven 与 Carey，2023 物种条目，页面标注更新于 2025-06-02。
- **URL**：https://avifauna.hkbws.org.hk/species/0050/006600
- **访问日期**：2026-10-24。
- **核对位置**：Vocalisations、Behaviour、Breeding、Range & Systematics。
- **证据**：记录竖起颈羽的缓慢鞠躬展示及相应鸣声；巢由细枝、根和草茎等构成，亦可位于建筑物。条目说明香港属于指名亚种，并交代部分名录的东西方拆分。
- **支持设计**：展示动作以颈与头部变化为识别点；巢体有少量细枝；可以抽象为桌面中的有承托巢位，而非一定建立整棵树。
- **不支持设计**：以大幅转身或上下平移替代真实姿态；把普通叫声等同求偶；推广为全部鸠鸽共用行为或上海精确季节表。

### S3：BirdLife Australia，直接确认松散枝条平台巢

- **标题**：*Spotted Dove*。
- **机构**：BirdLife Australia。
- **URL**：https://birdlife.org.au/bird-profiles/spotted-dove/
- **访问日期**：2026-10-24。
- **核对位置**：Bird Overview、Identification、Breeding。
- **证据**：明确使用 `Spilopelia chinensis`；描述雄鸟鼓起黑白颈斑附近羽毛、上下鞠躬；巢为细枝构成的松散平台；雌雄羽色相似。
- **支持设计**：M7c 首版选珠颈斑鸠平台巢的结论明确成立；保留鸟体颈斑身份特征；不靠换羽色猜性别。
- **不支持设计**：深而致密的编织篮、球巢或泥杯巢；因为羽色相似就推断自然中没有性别分工；把澳大利亚繁殖月份用于中国桌面季节。

### S4：Cornell，补充巢位和浅巢描述

- **标题**：*Spotted Dove Life History*，All About Birds。
- **机构**：Cornell Lab of Ornithology；条目参考 Garrett 与 Walker 2023 的 Birds of the World 物种资料。
- **URL**：https://www.allaboutbirds.org/guide/Spotted_Dove/lifehistory
- **访问日期**：2026-10-24。
- **核对位置**：Nesting → Nest Placement、Nest Description；Conservation 的分类说明。
- **证据**：通常在树／灌木枝上，巢是松散浅杯状枝巢，内衬可有羽毛与细根；同时提示不同分类体系对东西方珠颈斑鸠的处理。
- **支持设计**：有承托的浅盘平台可有轻微凹面与边缘起伏；“平台”不应理解为绝对平板。
- **不支持设计**：所有巢完全没有衬材；拿统一巢模板覆盖其他鸟种；从巢形直接推出动画时长。

### S5：Cornell，树麻雀有运材与筑巢依据，但不适合复用斑鸠平台

- **标题**：*Eurasian Tree Sparrow Life History*，All About Birds。
- **机构**：Cornell Lab of Ornithology。
- **URL**：https://www.allaboutbirds.org/guide/Eurasian_Tree_Sparrow/lifehistory
- **访问日期**：2026-10-24。
- **核对位置**：Nesting、Behavior。
- **证据**：可在树洞、建筑缝隙及巢箱等腔体营巢；草与秸秆构成的巢杯通常处于较大的球状草巢内，有侧入口或通道；雌雄均参与。求偶展示也与洞口、羽毛及翼尾动作相关。
- **支持设计**：如另开批次，明确做麻雀叼草／秸秆入洞、在入口消失后再出来；需另有洞口及遮挡素材。
- **不支持设计**：把树麻雀默认画成露天树枝平台巢；将所有巢都描述为树上裸露球巢；仅凭普通站立帧开放完整求偶。
- **本轮决定**：M7a–c 全部暂缓麻雀，不作为珠颈斑鸠的素材复用扩展。

### S7：北京喜鹊研究，确认带顶盖和入口的巢形

- **标题**：*Nest Site Selection of the Magpie Pica pica sericea in Beijing of China*。
- **作者／出版**：Zhengmei Wang、Yong Wang、Leszek Jerzak、Zhengwang Zhang；Studia Biologica，2010，4(1)：71–82；DOI：10.30970/sbi.0401.106。
- **URL**：https://publications.lnu.edu.ua/journals/index.php/biology/article/view/412
- **全文 URL**：https://publications.lnu.edu.ua/journals/index.php/biology/article/download/412/415
- **访问日期**：2026-10-24。
- **核对位置**：第 71 页摘要、第 74 页结果、第 76–77 页讨论。
- **证据**：2004–2006 年北京调查的 814 巢中，记录有顶盖和一至两个入口，双方参与建巢。论文用旧分类名；只采用北京研究对象的实测结论，不引用讨论中欧洲种群作为本项目物种事实。

## 4. 可见状态序列：与证据分开的产品编排

本节解释主规格中的画面与证据边界，不是自然行为逐帧复现，也不是现有实现声明。三个行为各自准入、各自结束；求偶展示完成不会自动建立巢或新增居民。具体前置条件、时长与资源结算直接查阅主规格。

### M7a：珠颈斑鸠的求偶姿态角色演示

**两只同种居民稳定站立 → 双方朝向 → 发起者抬身、颈部表现 → 缓慢鞠躬展示 → 观看者转头观察 → 双方恢复普通状态。**

- 动作依据：[S1][S2][S3]。首次只做原地鞠躬片段；走动包围、追赶和高空展示飞行明确暂缓。
- 按主规格必须有两只珠颈斑鸠，角色为 initiator / observer，只控制这次动画，不命名“雄鸟／雌鸟”“伴侣”。任一方失效则全组取消，另一方独立恢复；不把离开解释为关系下降。
- 鸟类说明可写“取材于自然中雄鸟的求偶姿态”；观察类别沿主规格的“求偶展示”，说明为风格化角色片段。禁止“配对成功”“繁殖关系已建立”等完成文案。
- 声音暂不作为首版前置条件；以后加入需独立核对鸣声和素材授权。无声演示属于产品取舍，不宣称还原完整求偶。
- 点击、警觉、宿主消失等可在任意阶段取消，立即恢复可控状态。普通站立或普通低头不能被记录成展示完成。

### M7b：珠颈斑鸠叼枝运材

**发现指定细枝 → 接近并预约 → 低头、喙触枝 → 拾取并衔住 → 带枝短途移动 → 在指定承托点停稳 → 放枝 → 空喙恢复 → 离开／回到普通行为。**

- 材料只用短细枝，与 [S1] 的衔材和 [S2][S3] 的巢材相符。喙夹点、枝条角度和路线是为小尺寸画面设计的抽象；不标注为论文测得的几何规律。
- [S1] 存在自然性别分工；产品单鸟完成取放只是角色片段，不表示该个体已被鉴定性别，也不声称复现了真实双鸟交接。
- 此批次使用主规格的巢台与材料盘，放下只增加已送达材料数，**不产生巢完成度**。不将枝条当作给用户的礼物，不增加礼物或熟悉度机制。
- 拾取前取消释放预约；附着后取消依公共回收规则处理，已原子拾取并扣库的材料按主规格记耗损，库存不返还，不凭空补枝。不得同时留在鸟喙和材料盘。
- 按主规格须完成放下、恢复并安全离开落稳后才记录运材完成；中途失效、回收或刚起飞均不冒充成功。

### M7c：珠颈斑鸠的简化浅盘枝平台

**M7b 单鸟运枝结束并释放租约（完成或放下后取消）→ 巢台有已送达未整理材料 → 下一次机会安排独立单鸟整理 → 朝向 → 低头调整 → 压实 → 原子提交消费一根已送达枝条、进度增加 → 抬身 → 安全离开 → 后续机会继续 → 达到视觉终态。**

- 巢位是独立巢台道具，依主规格放在合法地面或普通顶部边缘，同屏放置材料盘；宿主移动和失效按公共契约处理。承托画面应清楚，不能把巢画成无支撑悬空结构；具体外观由主规格与素材验收决定。
- 视觉档位为主规格的 **0/1/2/3：空巢台 → 少量交叉细枝 → 稀疏浅盘 → 完成的薄枝平台**。档位只描述画面成熟度，不代表真实枝数、天数或可繁殖性。[S1][S3][S4] 支持形态，不规定档数。
- 已投放枝条可并入预制巢图层，避免无限累积独立物件；完成后不再继续增长。不增加顶盖、洞口或泥墙。
- 单次机会只处理一根枝，运输与整理分属不同 run，不双记完成。每次仅一只鸟参与，即使不同次由不同个体演示，也不表示已配对或自然中任意个体合作建巢。
- 巢进度只在主规格指定的“整理压实后、进入抬身前”原子提交点增长；不能在 M7b 放枝时提前增长。提交前取消不增长，提交后取消保留进度但该 run 不记 completed。
- 第三根整理完成显示主规格的“巢台完成”，不额外制造第四条行为记录。无蛋、无雏鸟、无孵化倒计时；不以玩家离线、取消、清除或鸟离开制造繁殖失败叙事。

## 6. 工程风险与后续集中验收要求

以下基于本地 `World.swift`、`Species.swift`、`HabitatObjects.swift`、素材清单和现有路线图的规划判断；并非本次已实现或实测结果。这里只提出约束，不决定跨模块重构方案。

| 风险 | 后续应满足的行为边界 | 开发全部完成后统一核验 |
| --- | --- | --- |
| 素材／物种／运行条件混淆 | M7a–c 仅白名单 `spottedDove`；接触素材缺失应拒绝动作 | 自动与预览入口均不能使其他 45 种进入该行为；缺帧有明确原因 |
| 喙锚与镜像不一致 | 鸟、枝条、脚锚、实际帧尺寸使用明确坐标转换 | 0.5×／1×／2×、左右朝向及飞行各帧中，枝条夹点稳定、脚不漂移 |
| 现有飞行安全框不含枝条 | 当前 `landingFootprint` 和 `HabitatJourney` 包络按鸟体计算；携带后须覆盖突出枝条 | 狭窄落点、屏边、遮挡、另一只鸟附近，携带物也不穿越安全区 |
| 资源所有权与重复投放 | 材料库存、附着、送达未整理、已整理或耗损之间唯一结算；巢进度提交幂等 | 逐阶段点击、取消、超时、对象删除；不复制、不返还耗损枝、不重复增长 |
| 长于单次动作的巢状态 | 巢体跨多次访问存在；材料运输与巢生命周期独立，有容量上限 | 清除巢位时正在运材者安全退出；达到视觉终态后停止增长 |
| 移动／失效的桌面宿主 | 主规格巢台依赖合法承载面与同屏材料盘；不能假定现有 HabitatObject 已支持巢对象 | 关闭／移动窗口、睡眠唤醒、显示器移除、缩放改变时安全取消或清理 |
| 多鸟争抢与调度噪声 | 单访问槽、单材料预约；统一时钟与现有显著事件准入，不新增独立随机定时器 | 两鸟同时到达只有一个取得材料；暂停冻结；回放随机消费与语义版本明确 |
| 完成记录早于画面 | 送达材料、整理提交与 run 完成分别结算；巢终态只作 UI 状态 | 预览来源独立；取消／失败不记完成；第三次整理不额外添加第四条记录 |
| 暂存与重启复制 | 按主规格不跨重启保存场景对象与未完工巢台 | 退出无残留；重启不凭空复制材料或回放“完成”；以后保存需版本迁移设计 |
| 内容误导 | 文案说明角色演示；视觉完成与繁殖完全分开 | 不出现配对成功、性别判定、蛋／雏鸟奖励或离线繁殖结果 |

现有路线图已规定单一模拟时钟、行为所有权、取消恢复、预算和确定性重放，应沿其约束评估接入。M7b 先把携带与终点放置做完整，M7c 再复用；不要为了提前显示巢进度，把未完成运输记成投放成功。本轮不编译、不运行测试或原生验收。

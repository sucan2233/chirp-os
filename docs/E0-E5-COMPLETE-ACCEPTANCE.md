## 动作与权限边界

新增48种只审核观察、警觉、休息、起飞准备四项基础行为。其余管理行为仍待专项审核；不把54种加入原46种的隐式全通用权限，不扩食盘、浴盆、捕虫、求偶、赠礼、巢台或同伴互动。E0身份独立保留。手册对应实际四项可收集行为，特色闲置片段只做装饰，预览不产生观察记录。

每鸟沿当前造型、羽型、色板和既有idle方向制作风格化日常动作，分准备、重点、恢复、安定，使用两套稳定个体时序。这里的抬尾、探头、开喙等是产品化表现，不宣称已完成48种逐动作自然史考证；真实取食、求偶和栖地接触属于后续独立范围。缺资料的物种不臆造额外互动。

E4仅制作干燥落点上的姿态；䴙䴘的脚位和支撑独立处理。E5分别处理兀鹫宽翼、裸颈绒领、环颈雉长尾与鸠类鳞纹，不能套用小鸟比例。

模拟版本21→22，记录格式保持1。概率、旧设置、档案、16个现有道具与场景资格保持。旧模拟记录拒绝静默升级，22个历史场景从最终代码导出后检查语义变化。

## 性能对照与限制

固定12种新扩展鸟、种子73、全100种素材缓存；两版本使用相同测量源码，逐对交替运行。每轮10模拟秒预热、120模拟秒采样，共7200个60Hz样本；CPU时间使用`CLOCK_PROCESS_CPUTIME_ID`。结果仅含引擎与离屏绘制，不含系统合成器、真实窗口跟随或睡眠唤醒。

| 指标 | 基线三轮 | 当前三轮 | 三轮中位数变化 |

| 单帧CPU p95（毫秒） | 0.332 / 0.338 / 0.328 | 0.347 / 0.349 / 0.472 | 0.332→0.349，+5.12% |
| 素材加载CPU（秒） | 0.355313 / 0.333527 / 0.329765 | 0.377812 / 0.373540 / 0.374011 | +0.040484秒，+12.14% |

初始第三轮当前p95为0.472毫秒，明显高于另两轮，故追加三对短测。追加基线为0.334/0.349/0.338毫秒，当前为0.411/0.356/0.345毫秒；第四轮仍出现偏高值。原定三轮结果完整保留，不用追加结果替换。六轮p95的中位数为0.336→0.3525毫秒（+4.91%），但两次偏高值原因尚未确定，不能宣称尾延迟稳定达标或所有运行均低于10%增幅。

初始各轮采样末相对首个常驻内存样本均增加32KiB；这只是短测结果，不构成长时无泄漏结论。性能尾部波动保留为后续定位项，不因此重复进行用户已取消的长时间桌面观察。[原定三轮](evidence/e0-e5-complete-20261026/performance.json)、[追加三轮与完整六轮比较](evidence/e0-e5-complete-20261026/performance-followup.json)、[测量源码及二进制哈希](evidence/e0-e5-complete-20261026/benchmark-provenance.json)。

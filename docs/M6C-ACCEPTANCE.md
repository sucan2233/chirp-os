# M6c 验收记录

日期：2026-10-24。状态：实现与本批统一验证已完成，尚未替换用户正在使用的开发版。该记录不代表 M6d–M7d 已交付。

## 实现范围

- 新增白头鹎、红耳鹎、乌鸫、鹊鸲、暗绿绣眼鸟、灰喜鹊、红嘴相思鸟、纵纹腹小鸮各10帧，共80帧；另为白头鹎和鹊鸲各绘制3张探头专用帧。
- 探头名单4→6、固定栖木6→7、追逐和空中结队各6→7；同伴理羽、种子食盘和过境名单保持。
- 两种新探头鸟要求完整专用帧，运行和导出共用0.32/0.96/0.32秒 PoseClip，采样既有1.6秒观察阶段。
- 白头鹎栖木访问按实际 spriteScale 计算整鸟、8点逻辑余量及树枝合并空间，规划和运行时均验证。
- 设置页同源显示12鸟名单；素材和图集保留公共34帧、脚锚(29,39)及全部历史帧。

## 审查中的修正

增种会改变旧录制的拒绝/启动结果，因此将模拟语义升级提前到本批：10→11，录制格式仍为1。旧真实录制明确拒绝，不修改其版本标签冒充迁移。14份仓库手写夹具先以临时v11副本对照M6a/b完整报告，再迁移版本；不反向生成 expected。

纵纹腹小鸮起飞蹬伸的近侧翼横向投影由0.42收至0.18。修正前最右顶点为50.0454；修正后计保守0.5描边为47.2166，进入48点画布。脚锚和喙锚不变；原生验收增加画布触边 alpha 检查，M6c 的86帧已通过。旧家燕起飞帧顶部触边作为历史诊断保留，不改旧像素，也不宣称旧帧无触边。

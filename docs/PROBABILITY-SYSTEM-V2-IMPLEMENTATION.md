## 已实现行为

- macOS 及导出资源镜像采用同一份 100 鸟默认表，全部为正，总权重 5358。使用 120/90/65/45/30/18/10 七档；数值代表全国综合体验的人工设计，不代表实测全国遇见率。保护等级保留为研究信息，不作为自动权重乘数。
- 默认不勾选“手动调整概率”，不展示调整表。勾选后编辑独立相对权重，旁边显示实时计算占比。没有逐鸟开关、锁定或新鸟预算。输入允许 0 或 0.000001–1000000，合计无需为 100。
- 取消勾选后使用系统默认，保留不生效的覆盖值；重置清空覆盖、取消勾选并隐藏表，只作用于概率域。编辑、勾选与重置均需保存后生效。原有全设置恢复默认按钮仍可用于整体重置。
- 未编辑的 ID 始终跟随系统默认。新鸟自动取得默认权重；未知 ID 的覆盖值保留但不参与当前候选池。全零权重不生成新鸟，不强行均分或复活已排除鸟种。
- schemaVersion=2，概率字段为 `speciesProbability: {manualAdjustmentEnabled, overrides}`。v0/v1 旧概率校验后整体替换为系统默认，非概率偏好保留。旧文件首次保存前备份为 `settings.json.pre-probability-v2-<UUID>.bak`；读取不写盘，重复保存不重复迁移。损坏或未来版本文件拒绝覆盖。

## 底层与调用边界

Swift `WeightedChoice<Value>` 按候选顺序累计相对权重，先除以最大值避免总和溢出，并使用补偿求和。非法权重/随机输入报错；空池返回空且不消费随机值；随机输入为有限的 [0,1)。浮点极端跨度下的小权重仍受双精度分辨率限制。共享 fixture 覆盖零权重、空池、边界及极大/极小同倍缩放。

Swift 二选一、均匀离散、连续范围抽样集中到 `RandomChoice`；内部常量接口用前置条件验证。鸟种入场、群飞、生态候选抽样复用权重池。保留各领域独立随机流、时钟、资格和冷却条件。环境事件保留 8:4:1:87 的昆虫/求偶/赠礼/后续槽；关闭或冷却的槽继续消耗机会，后续叶片条件概率保持 1:9。候选资格过滤后才做权重抽样，不为新鸟赋予未实现的动作能力。

记录格式版本不变，模拟引擎版本 22 → 23；旧引擎录制不能冒充新引擎回放。共享行为夹具通过已有声明式场景导出器重新生成，再由独立语义断言验收。

## 设计落地说明

- 默认预设 ID/版本为代码常量 `cn-national-balanced-v2` / 1。保存文件不复制默认表、不持久化推导百分比；调研 JSON 的 `catalogSha256` 表示改权重前的研究基线。
- 概率页面沿用原生纵向鸟种列表；当前实现没有新增搜索/排序控件。稳定 ID 决定覆盖关系，显示顺序不改变抽样契约。
- 本轮不修改用户真实设置，不安装替换正在使用的版本，按用户要求进行本地 Git 提交；未推送或发布。

# 啾啾 Pro 0.8.2

面向 macOS Apple Silicon 的百鸟动作增强与独立更新版本。

- 包含 M8 与 E0–E5：100 种鸟具备增强基础姿态和特色动作，全目录 4867 帧槽。
- 支持自维护 GitHub 更新通道、Ed25519 签名验证、下载、确认安装与重启，以及启动失败回滚。
- 修复携叶路径在云端 Swift 编译器上的类型推断超时；检查并拆分结伴飞行、捕虫的同类曲线表达式，保持控制点、采样数量与原有公式。
- 云端日志记录 Xcode 与 Swift 版本，方便定位工具链差异；完整核心测试继续使用 Release 模式。

0.8.0 未完成云端编译；0.8.1 首次因 GitHub 托管 runner 分配失败取消，重跑后发现携叶曲线编译问题。这两个版本均未发布安装包，保留原标签和运行记录。

此前 0.6.0 Pro 测试包关闭更新，需要手动安装本版本一次。先退出旧版，将应用移到“应用程序”目录；已有设置和观鸟记录沿用。没有 Apple 公证，首次打开网络下载包可能需要在 macOS“隐私与安全”中确认。

M9 暂缓；性能尾部波动、真实窗口跟随、菜单暂停/恢复、睡眠唤醒和外接屏等历史未验项仍保留。完整远程升级与真实退出、重启仍需另行验收。

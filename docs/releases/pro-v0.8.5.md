# 啾啾 Pro 0.8.5

面向 macOS Apple Silicon 的百鸟动作增强与独立更新版本。

- 包含 M8 与 E0–E5：100 种鸟具备增强基础姿态和特色动作，全目录 4867 帧槽。
- 支持自维护 GitHub 更新通道、Ed25519 签名验证、下载、确认安装与重启，以及启动失败回滚。
- 拆分云端编译报错的求偶、捕虫、携叶测试夹具及原生验收表达式，明确 CGFloat 与可选整数类型，保持原有行为与验收标准。
- 拆分求偶测试中左右方向位置数组的三元表达式，避免 Swift 6.2.4 在组合运算上的类型推断超时。
- 拆分场景导出中携叶、捕虫、筑巢、互相理羽的多段帧数组拼接，保留帧序列和场景语义。
- 拆分编译耗时诊断发现的互相理羽、追逐及求偶设置验收表达式，保持原有几何与判定条件。
- 发布工作流固定 Xcode 26.3，记录实际 Xcode/Swift 版本，完整核心测试使用 Release 模式。

0.8.0–0.8.4 均未发布安装包；0.8.2 的完整日志确认云端默认 Xcode 16.4 / Swift 6.1.2 与本机工具链存在差异。0.8.3 已将云端固定为 Xcode 26.3 / Swift 6.2.4，并消除了其余已报错误；0.8.4 修复位置数组后进一步暴露场景导出的长数组拼接超时；本版本拆分同类拼接，保留历史标签。

此前 0.6.0 Pro 测试包关闭更新，需要手动安装本版本一次。先退出旧版，将应用移到“应用程序”目录；已有设置和观鸟记录沿用。没有 Apple 公证，首次打开网络下载包可能需要在 macOS“隐私与安全”中确认。

M9 暂缓；性能尾部波动、真实窗口跟随、菜单暂停/恢复、睡眠唤醒和外接屏等历史未验项仍保留。完整远程升级与真实退出、重启仍需另行验收。

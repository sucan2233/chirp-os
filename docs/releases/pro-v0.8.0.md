# 啾啾 Pro 0.8.0

首个具备独立更新通道的Pro版本，面向macOS Apple Silicon。

- 包含M8与E0–E5的百鸟动作增强：100种鸟具备增强基础姿态和特色动作，全目录4867帧槽。
- 新增自维护GitHub仓库的版本检查、签名验证、更新下载、确认安装与重启，以及失败回滚流程。
- 更新包使用独立Ed25519密钥签名，客户端只接受固定公钥及Pro版本通道。
- 沿用此前测试版设置和观鸟记录，菜单显示“啾啾 Pro / ChirpOS Pro”。

此前0.6.0 Pro测试包关闭更新，需要手动安装本版本一次。安装前先退出旧版，再将应用移到“应用程序”目录。没有Apple公证，首次打开网络下载包可能需要在macOS“隐私与安全”中确认。

M9尚未开发；性能尾部波动、真实窗口跟随、菜单暂停/恢复、睡眠唤醒和外接屏等历史未验项仍按交付文档保留。本版不宣称这些项目已通过。

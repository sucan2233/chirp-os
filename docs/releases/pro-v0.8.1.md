# 啾啾 Pro 0.8.1

面向 macOS Apple Silicon 的百鸟动作增强与独立更新版本。

- 包含 M8 与 E0–E5：100 种鸟具备增强基础姿态和特色动作，全目录 4867 帧槽。
- 支持自维护 GitHub 更新通道、Ed25519 签名验证、下载、确认安装与重启，以及启动失败回滚。
- 拆分访客送礼飞行曲线的计算，解决 GitHub macOS Swift 编译器的类型推断超时，保持原有路径公式与采样数量。
- 发布脚本的隔离测试固定夹具版本，避免后续产品版本递增导致测试失效。
- 发布流水线使用 Release 模式执行完整核心测试，保留全部用例并减少行为仿真耗时。

0.8.0 的首次云端构建失败，未发布安装包；保留其标签和失败记录，本次使用新版本重新发布。

此前 0.6.0 Pro 测试包关闭更新，需要手动安装本版本一次。安装前先退出旧版，再将应用移到“应用程序”目录。沿用已有设置与观鸟记录。没有 Apple 公证，首次打开网络下载包可能需要在 macOS“隐私与安全”中确认。

M9 暂缓；性能尾部波动、真实窗口跟随、菜单暂停/恢复、睡眠唤醒和外接屏等历史未验项仍保留。完整远程升级与真实退出、重启仍需另行验收。

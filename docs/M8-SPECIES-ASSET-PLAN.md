日期：2026-10-26。状态：U整合后更新规划，尚未制作。当前素材基线：`143217e`；按 `shared/species.json`、`shared/art/manifest.json` 与 `shared/species-support.json` 核对。总体范围和验收见 [M8 M9 生态完善计划](M8-M9-ECOLOGY-PLAN.md)。

[上游v0.7整合U阶段](UPSTREAM-V0.7-INTEGRATION-PLAN.md)已接入100种目录。下表固定原46种增强对象；新54种基础图集已交付，不扩大本表524帧预算。本次已逐鸟复核现有帧数，原46种仍合计1751帧位；U已改变部分旧帧像素，因此绘制与差异检查使用`143217e`，尤其保留 `greatTit` 的形象与元数据修正。

新54种现已完成[动作能力盘点与候选分批](EXPANSION-54-CAPABILITY-PLAN.md)，以稳定ID和[全100种能力矩阵](evidence/expansion-capability-audit-20261026.json)与本表连接。原46种M8a是6种74帧；新54种E0候选是另外6种、按同等模板估算84帧，尚未制作，两者不能混记为同一批。

本表46种鸟每种现有34个公共帧名，已有不同轮廓与物种闲置动作。增强基础包有10帧，当前12种具备、34种缺少；白眉姬鹟虽有3帧捕虫，仍缺这10帧。每种鸟另规划4帧特色动作，形成至少一个有准备、重点和恢复的完整片段，允许复用原有站立帧作两端，但不能将旧帧复制后计为新增。

下表的动作是制作方向，不是46种习性全部完成考证。`设计`表示沿既有动作类别安排的风格化姿态；`R1/R2`见总体计划的物种来源，来源只支持其中的自然行为，时序和4帧拆分是产品决定。带有食物、树干、水面或社交语义的动作必须满足相应宿主和行为资格；中性姿态不解锁专用互动。

每批交付需另记实际完成帧数、实际图集变化、代码净增减、通过检查及未验项目。若4帧无法清楚表达动作，应调整该鸟预算和总表，不能用重复帧填数，也不能默默少交。

## U后制作与交付调整

- 先完成M8a六种样板：74帧预算、至少6个完整特色片段、每个片段至少2种稳定时序；基础包从12种增至17种。M8b再增8个特色片段，两批合计14种、106帧，基础包仍为17种。
- 每鸟记录新增帧槽、物种内不同画面、完整片段、时序变体及图集文件变化；预览、镜像和既有帧复制不算新增素材。4帧特色预算可以在样板证据基础上调整，调整时同步本表和总计划。
- 百鸟能力核对覆盖新54种，但只产出缺口与优先级，不生成其增强包、不开放食盘/浴盆等新资格。复用现有支持导出的显式回退与审核字段。
- 手册复用U的统一入口：预览不计发现或完成，装饰动作不另设收集任务。需要真实宿主的片段仍按白名单与运行条件准入。
- U原生失败的定向收口与素材准备可并行；确认影响共享调度或生命周期的缺陷，要在相关片段交付前修复。无设备与用户已接受的未验项不阻塞独立内容制作。

本表动作方向和物种名单保持不变；当前只更新基线、统计和交付要求，不代表已经新增524帧或开始M9场景开发。

## 4. 明确排除而非证据否定

未开放的含义是本期没有对应内容交付，并不代表该鸟在自然界不会洗澡、不会捕虫或不会求偶。夜鹭/其他长腿鸟、猛禽/鸮、水鸟和长喙鸟不套小型鸟接触模板；现有结构、体型与动作保持。喜鹊大型巢、家燕泥巢等有不同素材/场景需求，已在主规格列为后续独立提案，不让开发 agent 自行替换成珠颈斑鸠的枝条平台。
